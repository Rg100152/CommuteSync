## 🎯 Overview

**CommuteSync** is a next-generation multi-modal transportation platform that seamlessly integrates car pooling, bike sharing, and micro-mobility solutions. The platform leverages blockchain technology for carbon credit tracking, trust-graph verification for safety, and gamification for user engagement.

The platform features:
- **Multi-Modal Routing** - Hybrid car + bike optimization
- **Trust-Graph Verification** - Professional network validation
- **Blockchain Carbon Ledger** - Tokenized environmental rewards
- **Corporate ESG Integration** - Enterprise sustainability tracking
- **Gamified Engagement** - Achievement-based incentives
- **Real-time Matching** - Smart commuter pairing

## 🔬 How It Works

### Commuting Flow
```
User Registration → Profile Verification → Route Selection → Smart Matching → Multi-modal Journey → Carbon Rewards
```

### Smart Match Engine
1. **Route Analysis** - Compare commuter paths
2. **Multi-Modal Options** - Car + bike combinations
3. **Trust Verification** - Professional connections
4. **Carbon Calculation** - CO2 savings estimation
5. **Token Generation** - GreenCredit minting

## 📦 Installation

### Prerequisites
- Modern web browser
- Internet connection for CDN resources

### Setup Steps

1. **Clone Repository**
   ```bash
   git clone https://github.com/Rg100152/commutesync.git
   ```

2. **Navigate to Directory**
   ```bash
   cd commutesync
   ```

3. **Run Application**
   ```bash
   # Python Server
   python -m http.server 8000
   
   # Node.js
   npx serve
   
   # VS Code
   # Install Live Server extension
   # Right-click index.html → "Open with Live Server"
   ```

4. **Access Platform**
   - Open `http://localhost:8000`
